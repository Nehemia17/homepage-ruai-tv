1. PRODUCT REQUIREMENTS DOCUMENT (PRD)
1.1 Executive Summary & Purpose
Dokumen ini merinci kebutuhan produk untuk pengembangan website portal/homepage resmi stasiun televisi Ruai TV (Kalimantan Barat). Website ini dirancang untuk menyajikan informasi menyeluruh tentang profil stasiun televisi, program unggulan, katalog seluruh program (aktif dan arsip), jadwal penayangan mingguan (sepekan), serta direct redirect interaktif menuju live streaming YouTube Ruai TV. Desain mengadopsi estetika clean modern, Bento-Grid modular cards, dan skema warna khas identitas Ruai TV (merah, emas, dark charcoal, dan putih).
1.2 User Personas & Pain Points
* Pemirsa Lokal & Diaspora Kalbar: Memerlukan akses instan untuk mengetahui jam tayang program favorit mereka (Warta Ruai, Rumah Kita, Special Dialog, Gong Ruai) dan tautan siaran langsung YouTube.
* Mitra Kerja Sama & Klien Korporasi: Mencari informasi profil perusahaan, jangkauan kanal transmisi (UHF/Satelit), dan jenis program kemitraan (VOA, CBN, Dokumenter Lingkungan).
* Internal Tim Redaksi/Broadcast Ruai TV: Memerlukan sistem manajemen data yang fleksibel untuk meng-update slot jam tayang, mengubah status arsip/aktif, atau memperbarui ringkasan deskripsi program tanpa merusak layout desain.

2.3 Logika Implementasi Komponen Teknis
A. Sistem Filter Katalog Program
1. Tiap kartu memiliki atribut data: data-category (berita, non-news, kerja-sama) dan data-status (aktif, arsip).
2. Tombol filter aktif memicu event listener yang mencocokkan status tab dengan item:
   * Tab Semua: Menampilkan seluruh elemen DOM kartu (remove class hidden).
   * Tab Aktif: Menampilkan elemen yang memiliki data-status="aktif".
   * Tab Arsip: Menampilkan elemen yang memiliki data-status="arsip".
   * Tab Kategori (Program Berita, Non-News, Kerja Sama): Menampilkan elemen yang sesuai dengan atribut data-category.
3. Badge angka di samping tab dihitung secara reaktif melalui Array.filter() sesuai dataset yang aktif.
B. Modal Dialog Controller
1. Implementasi native menggunakan elemen HTML <dialog id="program-modal"> atau custom overlay fixed inset-0 z-50 dengan backdrop blur backdrop-blur-sm bg-black/60.
2. Saat kartu diklik, fungsi openProgramModal(programId) akan membaca data program dari cache memory/JSON dan menginjeksi isi:
   * Judul program, durasi, dan format pada header modal.
   * Header modal berganti kelas warna background: bg-gradient-to-r from-orange-600 to-red-600 jika status = "aktif", atau bg-[#2B2B2B] jika status = "arsip".
   * Rendering slot jadwal: Kartu jadwal yang aktif diberi background merah solid bg-[#C81E2E] dengan teks putih tebal, sedangkan slot yang tidak tayang diberi background putih dengan border abu-abu dan teks redup "Tidak tayang".
   * Jika program berstatus aktif, tombol CTA "Streaming / Live" ditampilkan di bagian bawah modal dan diarahkan ke link YouTube Live dengan atribut target="_blank" rel="noopener noreferrer".
3. Accessibility: Modal menangkap event keydown untuk tombol Escape agar menutup otomatis, dan mengunci scroll body (overflow: hidden) saat terbuka.
C. Tabel Matriks Jadwal Siaran Sepekan (Mobile Swipe Strategy)
1. Komponen tabel dibungkus di dalam container berkelas w-full overflow-x-auto scrollbar-thin scrollbar-thumb-neutral-700.
2. Lebar minimum tabel diatur ke min-w-[850px] untuk mencegah teks jam tayang dan judul program bertumpuk di resolusi ponsel (portrait).
3. Ditambahkan elemen indikator visual di bawah tabel khusus untuk tampilan layar kecil (md:hidden): "Geser horizontal untuk melihat jadwal lengkap →".
